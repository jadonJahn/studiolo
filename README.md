# Studiolo

A focus timer that paints a one-of-a-kind generative artwork while you work. Each session gets its own seed, and the piece builds as the session goes on. Finished pieces are saved to your gallery.

- Pomodoro, countdown and stopwatch modes, with tasks, activities and stats
- Seven art styles (flow fields, harmonographs, nebulae, aurora and more) that can react to the music you're playing (Windows)
- A floating mini timer that stays on top of other windows while you work
- Everything stays on your device: no account, no telemetry

The app lives in [`app/`](app/). See [app/README.md](app/README.md) to run or build it (web/PWA, or a Windows desktop app via Tauri).
