## Unreleased

First public release.

- Focus timer with Pomodoro, countdown and stopwatch modes, tasks, activities and stats.
- Seven generative art styles that paint as you focus, saved to a gallery.
- Floating mini timer over other windows (desktop), or a Picture-in-Picture pop-out (Chromium browsers).
- Focus view options: clock always / when active / never; pin or hide each set of buttons.
- Music-reactive art and now playing (Windows).
- Optional read-only local data API, off by default.
- In-app updates for the Windows app, a welcome screen, and copyable diagnostics for bug reports.
